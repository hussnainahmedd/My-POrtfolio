# 🌌 Hussnain Ahmed - Developer Portfolio

Welcome to the official repository of my personal developer portfolio! This project showcases my skills, experience, and the incredible projects I have built throughout my journey as a Computer Science undergraduate. 

![Portfolio Preview](./src/assets/hero.png) *(Preview placeholder)*

## 🚀 Features

This portfolio is not just a standard resume—it is a deeply interactive, 3D web experience built with modern frontend technologies.

- **Nebula Background**: A custom, pure-CSS animated glowing orb background that reacts smoothly behind the content.
- **3D Interactive Project Carousel**: An incredible auto-rotating 3D cylinder that maps out 18 of my top GitHub repositories. You can drag to spin it, and hover to pause and inspect individual project cards.
- **Dynamic 3D Skill Sphere**: A Fibonacci lattice-based glowing text sphere displaying my complete technical arsenal (Java, Python, React, Firebase, Node.js, and more). It mathematically distributes skills in a 3D space and reacts to mouse movement.
- **Premium Glassmorphism UI**: Beautifully frosted cards, custom custom-cursor tracking, and magnetic buttons that playfully pull towards your mouse.
- **Functional Contact Form**: Integrated with Web3Forms to allow visitors to send emails directly to my inbox without needing a local mail client.
- **Lenis Smooth Scrolling**: Ultra-fluid scrolling mechanics integrated directly with GSAP ScrollTrigger.

## 💻 Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Language**: TypeScript
- **Styling**: Vanilla CSS with curated CSS variables and Glassmorphism design principles.
- **Animations**: GSAP (ScrollTrigger), Native CSS 3D Transforms, and `requestAnimationFrame` hooks.
- **Icons**: Lucide React
- **Email Service**: Web3Forms

## 📂 Project Structure

- `src/App.tsx`: The main orchestration file assembling the Hero, About, Work, Skills, and Contact sections.
- `src/Carousel3D.tsx`: The mathematics and logic behind the interactable 3D rotating project cylinder.
- `src/SkillSphere.tsx`: The logic for the auto-rotating 3D text globe built without external WebGL libraries.
- `src/MagneticButton.tsx`: Custom interactive wrappers that create the playful "pull" effect on buttons.
- `src/ContactForm.tsx`: A secure and fully functioning form component.
- `src/NebulaBackground.tsx`: The animated glowing background elements.

## 🛠️ Getting Started Locally

Want to run this portfolio on your own machine? It's incredibly easy.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hussnainahmedd/My-POrtfolio.git
   cd My-POrtfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
